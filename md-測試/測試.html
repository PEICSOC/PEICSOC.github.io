### struct配合sort、cmp

strust也可以用成陣列：
```cpp!
#include <bits/stdc++.h>
using namespace std;
struct a{
    int x=3;
    int y=4;
};

int main(){
    a n[2];
    n[1].x=1;
    cout<<n[0].x<<" "<<n[0].y<<" "<<n[1].x<<" "<<n[1].y;
}

    輸出：
    3 4 1 4

    當我輸入一串資料，假設今天辦活動，每位大人要和一位小朋友參加，所以輸入了大人和小孩的歲數：
    | 大人 | 小孩 |
    |-|-|
    | 50 | 10 |
    | 40 | 12 |
    | 34 | 13 |
    | 40 | 15 |
    | 25 | 16 |

    假設我要把這5組資料排序，依照大人由小到大排序，如果大人歲數一樣，依照小朋友由大到小排序。
    這樣要怎麼做?

    ```cpp!
    #include
    using namespace std;
    struct a{
    int x=3;
    int y=4;
    };

    bool cmp (a left,a right){
    if(left.x==right.x){
    return left.y>right.y;
    }
    return left.x<right.x;
    }

    int main(){
    a n[5];
    n[0].x=50,n[0].y=10;
    n[1].x=40,n[1].y=12;
    n[2].x=34,n[2].y=13;
    n[3].x=40,n[3].y=15;
    n[4].x=25,n[4].y=16;
    sort(n,n+5,cmp);
    for(int i=0;i<5;i++){
    cout<<n[i].x<<" "<<n[i].y<<endl;
    }
    }

    這樣就可以根據小孩來排列了

## 定義與自動輸入


(直接問19)

### 1. 定義
```cpp
#define nn \n

    這邊要教的是「定義」這件事情
    如果我們今天要輸出1我們會寫程式碼向下面這樣
    ```cpp!
    #include
    using namespace std;
    int main(){
    cout<<1;
    }

    那如果我們要輸出
1
1
1
三個換行的1，我們會打下面的程式
```cpp!
#include<bits/stdc++.h>
using namespace std;
int main(){
    cout<<1<<"\n"<<1<<"\n"<<1;
}

    這樣子做可以輸出換行的三個1，只是這樣太麻煩了，輸入"要按Shift，輸入\還要找位置好麻煩，如果只要輸入一個短短的字就可以取代"\n"的話那該有多好?

    於是工程師就發明了#define這個工具

    我們可以把程式寫成這樣：
    ```cpp=
    #include
    using namespace std;
    #define nn "\n"
    int main(){
    cout<<1<<nn<<1<<nn<<1;
    }

    第3行的`#define nn "\n"`的意思是把程式碼中所有的`nn`換成`"\n"`，所以第五行中的`cout<<1<<nn<<1<<nn<<1;`就會換成`cout<<1<<"\n"<<1<<"\n"<<1;`，達到換行的效果

這功能能夠簡化所有「不想要打這麼多字」的地方，減少撰寫程式碼之時間。

但這項功能不能使用於標頭檔以及資料型態（例如：int不能被替換），盡量不要使用於變數名稱，不然出問題系統偵錯不到。






### 2. 自動輸入
```cpp
istream& ss = cin;

    在這邊要講解的是自動輸入，就是讓程式執行時自動輸入要輸入的東西

    假設今天有一個題目：請輸入20個人的身高，算出總合。
    輸入：
    150 162 180 175 174 163 144 153 165 164 152 184 156 154 165 187 176 168 169 174
    輸出：
    3315

    我們可以寫一個程式來執行，如下
    ```cpp=
    #include
    using namespace std;
    #define nn "\n"
    int main(){
    int all=0;
    int x;
    for(int i=0;i<20;i++){
    cin>>x;
    all+=x;
    }
    cout<<all;
    }

    著個程式輸入20個數字並加總，是個簡單的程式，假設今天你的電腦失去了`Ctrl + C`、`Ctrl + V`功能，也就是不能複製貼上。

每測試一次測資看自己的程式有沒有錯就要輸入20筆資料，即便打字速度快，你能保證每次輸入的數字都對嗎?更何況打字速度慢的同學，這將會非常痛苦。

你可能會說實際上幾乎不可能`Ctrl + C`、`Ctrl + V`失靈，但真的會如此!!!!
APCS考場的電腦是無法複製貼上的，這時候我們可以使用一個偷懶方法，把程式碼改成這樣：
```cpp=
#include<bits/stdc++.h>
using namespace std;
#define nn "\n"
stringstream ss("150 162 180 175 174 163 144 153 165 164 152 184 156 154 165 187 176 168 169 174");
int main(){
    int all=0;
    int x;
    for(int i=0;i<20;i++){
        ss>>x;
        all+=x;
    }
    cout<<all;
}

    我們修改了甚麼?
    我們在第4行增加了stringstream ss("150 162 180 175 1....，把第9行的cin>>x;改成ss>>x;這些程式碼是甚麼意思呢?

    首先我們要知道cin可以想像成一個空間，我們輸入這20個數字用空白鍵或是換行分開時，他會先存到cin這個空間中，每次執行程式碼cin>>x時電腦會把cin中的第一組數字，也就是在第一個空白鍵或是換行之前的所有東西丟給x，然後把丟給x的東西刪除，過程如下，以輸入5個人的身高為例。

    1. 輸入1 2 3 4 5
      輸入完電腦把輸入丟給cin，此時的cin如下：
      cin(1 2 3 4 5)

    2. 執行程式cin>>x，cin把第一個空白鍵或是換行之前的所有東西丟給x
      此時的cin和此時的x如下：
      cin(2 3 4 5)
      x(1)
      可以看到cin中的1不見了

    3. 再執行一次cin>>x
      cin(3 4 5)
      x(2)
      可以看到cin中的2不見了
      …
      …
      …

    以此類推

    了解了這些，我們再看到程式碼更改的地方，我們在第4行增加了stringstream ss("150 162 180 175 1....這邊的stringstream ss之中stringstream是資料型態，ss是變數名稱，其實stringstream跟cin是個類似的東西。

    當執行到第4行的stringstream ss("150 162 180 175 1....時，意思是把括號中的東西給ss，也就是把我們要輸入的東西丟給ss，現在ss內容為：
    ss(150 162 180 175 174 163 144 153 165 164 152 184 156 154 165 187 176 168 169 174)

    接下來當程式執行到ss>>x時，ss會把第一個空白鍵或是換行之前的所有東西丟給x，如下：

    ss(162 180 175 174 163 144 153 165 164 152 184 156 154 165 187 176 168 169 174)
    x(150)

    如此一來我們只要直接執行程式，程式就會自動幫我們打好要輸入的東西，我們也只需要檢查一次資料的正確性即可。
    :::danger
    當我們想要上傳程式碼至系統或是手動輸入時，只要把ss>>x改成cin>>x即可，
    畢竟不可能拿自動輸入的程式給系統驗證
    :::

    但如果我們寫了一大串程式，程式中有很多cin的話，我們每次上船程式碼都要每個cin修改慢慢修改，這樣不是超級累

    這時我們可以更進一步的偷懶，把程式碼改成這樣：
    cpp= #include<bits/stdc++.h> using namespace std; #define nn "\n" stringstream ss("150 162 180 175 174 163 144 153 165 164 152 184 156 154 165 187 176 168 169 174"); istream& ss = cin; int main(){ int all=0; int x; for(int i=0;i<20;i++){ ss>>x; all+=x; } cout<<all; } 

    這邊我們只增了第5行的`istream& ss = cin;`這一行的意思是用cin把ss代替，也就是讓`ss>>x`變為`cin>>x`。當我們想要手動輸入時，我們把第4行註解，如下：
```cpp=
#include<bits/stdc++.h>
using namespace std;
#define nn "\n"
//stringstream ss("150 162 180 175 174 163 144 153 165 164 152 184 156 154 165 187 176 168 169 174");
istream& ss = cin;
int main(){
    int all=0;
    int x;
    for(int i=0;i<20;i++){
        ss>>x;
        all+=x;
    }
    cout<<all;
}
    當我們要自動輸入時，改為第5行註解，如下：cpp=
    #include
    using namespace std;
    #define nn "\n"
    stringstream ss("150 162 180 175 174 163 144 153 165 164 152 184 156 154 165 187 176 168 169 174");
    //istream& ss = cin;
    int main(){
    int all=0;
    int x;
    for(int i=0;i<20;i++){
    ss>>x;
    all+=x;
    }
    cout<<all;
    }
    如此一來就不用找到每個cin慢慢換成ss了，切換時我們要做的動作只有移動註解「//」的位置而已，只不過要記得寫主程式時所有的cin要寫成ss。

### 1.對於for迴圈之統一
我們都統一在for迴圈的第一層用i，第二層用j，第三層用k

原因：
1. 三個連續的英文字母鍵盤位置相近
2. 撰寫程式的「慣例」，工程師基本上都被要求這樣寫，統一後在閱讀時較為方便，有時候自己的程式碼可能會被別人看

如下：
```cpp=
#include<bits/stdc++.h>
using namespace std;
int main(){
    
    for(int i=0;i<n;i++){
        for(int j=0;j<n;j++){
            cout<<"...";
        }
    }
    
    for(int i=0;i<n;i++){
        for(int j=0;j<n;j++){
            for(int k=0;k<n;k++){
                cout<<"...";
            }
        }
    }
    
    
    for(int i=0;i<n;i++){
        cout<<"...";
    }
}
