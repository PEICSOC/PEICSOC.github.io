
# 複雜度

每秒 $10^7$

| Big-O 複雜度 | 競賽適用範圍                     |
|--------------|----------------------------------|
| $O(n!)$      | $n \leq 10$                     |
| $O(2^n)$     | $n \leq 20$                     |
| $O(n^4)$     | $n \leq 50$                     |
| $O(n^3)$     | $n \leq 200$                    |
| $O(n^2)$     | $n \leq 3000$                   |
| $O(n \log n)$| $n \leq 10^6$（有時候 $n = 10^7$ 也不會 TLE） |
